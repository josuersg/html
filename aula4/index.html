O que é estruturação semântica?

Semântica é um termo relacionado ao "significado". Escrever HTML semântico significa utilizar elementos HTML
que estruturam o conteúdo de acordo com a função de cada trecho, e não apenas com a forma como ele será exibido visualmente.

Por que a estruturação semântica em HTML é importante

O uso de elementos semânticos no HTML permite que os mecanismos de busca e outras ferramentas compreendam com clareza o papel de cada parte do conteúdo.
